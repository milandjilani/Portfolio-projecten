Schoolbeheer

Dit is een app die ik heb gemaakt als verzonnen opdracht, puur om mijn skills te testen. Ik heb hem gemaakt in C# met WPF en een MySQL-database.

In de app kan ik studenten, docenten, klassen en vakken toevoegen en verwijderen. Ik kan ook een docent aan een klas koppelen en een student aan een vak. Als er iets niet klopt, kan ik de gegevens van studenten en docenten ook aanpassen.

Zelf proberen

Ik gebruik Visual Studio en MySQL (via Laragon). Ik heb een database gemaakt met de naam schoolbeheer en daarin de tabellen studenten, docenten, klassen, vakken, student_vak en docent_klas. Daarna open ik schoolbeheer.csproj in Visual Studio en start ik het project.

Let op: de verbinding met de database staat in de code op localhost, met gebruiker root en geen wachtwoord. Als jouw instellingen anders zijn, moet je dat aanpassen.

Quiz over bananen

Dit is een quiz die ik voor school heb gemaakt in HTML, CSS en JavaScript. Alle vragen gaan over bananen.

Ik kies eerst hoeveel vragen ik wil (tussen de 1 en 20) en klik op Start Quiz. De vragen komen in willekeurige volgorde en bij elke vraag zijn er vier antwoorden. Ik heb 10 seconden per vraag, anders gaat hij vanzelf door naar de volgende. Aan het eind zie ik mijn score.

Zelf proberen

Je hoeft niks te installeren. Download de map en open eind.html in je browser.

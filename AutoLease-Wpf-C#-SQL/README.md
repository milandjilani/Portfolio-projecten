BestCars (AutoLease)

Dit is een app die ik voor school heb gemaakt om auto's, klanten en leasecontracten bij te houden. Ik heb hem gemaakt in C# met WPF en een MySQL-database.

In de app kan ik auto's en klanten toevoegen en een auto aan een klant koppelen met een start- en einddatum. In het overzicht zie ik alle contracten. Daar kan ik de datums aanpassen of een contract opzeggen.

Zelf proberen

Ik gebruik Visual Studio en MySQL (via Laragon). Ik heb een database gemaakt met de naam autopagina en daarin de tabellen autogegevens, klanten en leasecontracten. Daarna open ik ideavoorstel_auto_lease.csproj in Visual Studio en start ik het project.

Let op: de verbinding met de database staat in de code op localhost, met gebruiker root en geen wachtwoord. Als jouw instellingen anders zijn, moet je dat aanpassen.

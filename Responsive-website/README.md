TechBits (responsive website)

Dit is een website die ik voor school heb gemaakt voor een verzonnen webshop met kleine tech-gadgets. Ik heb hem gemaakt in HTML, CSS en een beetje JavaScript. Het doel was dat de site er goed uitziet op zowel een computer als een telefoon.

De site heeft een landingspagina en een contactpagina met een formulier. Op mobiel verandert het menu in een hamburgermenu, dat werkt met een paar regels JavaScript. Voor de verschillende schermformaten heb ik media queries gebruikt.

Zelf proberen

Je hoeft niks te installeren. Download de map en open Landingspagina (desktop).html in je browser. Maak het venster kleiner om te zien hoe de site meebeweegt.

Let op: het contactformulier verstuurt nog niks en een paar links in het menu (zoals inloggen en winkelmandje) verwijzen naar pagina's die ik niet heb gemaakt.

Vissen-aquarium

Een aquarium-app gemaakt in C# met WPF, waarin ik vissen kan toevoegen die rondzwemmen.

Ik geef een vis een naam en kies of hij vrolijk is, want dat bepaalt hoe hij beweegt. Ik kan ook zelf een vis maken met een eigen kleur, grootte en breedte, en planten toevoegen. Vissen kan ik weer verwijderen door een kleur in te vullen, en met de resetknop maak ik het hele aquarium leeg. De vissen die ik maak komen in een lijst en worden ook opgeslagen in een tekstbestand (gegevens.txt).

Zelf proberen

Ik gebruik Visual Studio. Voor de kleurkiezer gebruik ik het pakket Extended.Wpf.Toolkit, dat Visual Studio zelf downloadt als je het project opent. Ik open eindopdracht csharp.csproj in Visual Studio en start het project. Je hebt hiervoor geen database nodig.
